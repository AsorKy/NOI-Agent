# 📘 NOI agentic workflow for well interventions

The NOI Generator is a multi-agent flow that serves as an assistant for creating Notification of Intent reports, which are generated based on historical public information on oil well interventions. This project consists of three blocks:

- RAG engine: The RAGFlow ecosystem is used as the main RAG search engine for the user. The database generated by this ecosystem is also used as the main source of operation for the application.

- N8N: Process orchestrator.

- Report generator: Second layer of multi-agent flow that uses the information extracted by the RAG engine and orchestrated by N8N to generate the final NOI report.

💾 6. Extraer datos de la base de datos MySQL

RAGFlow usa MySQL para almacenar artefactos críticos (chunks, embeddings, metadatos).

6.1 Verificar la contraseña de MySQL

Ejecuta dentro del contenedor de MySQL:
docker exec ragflow-mysql env | grep MYSQL_ROOT_PASSWORD

Ejemplo de salida:
MYSQL_ROOT_PASSWORD=mi_contraseña_segura


6.2 Hacer un dump completo de la base de datos rag_flow

Ejecuta desde el host (PowerShell o bash), reemplazando MICONTRASEÑA por la contraseña obtenida:

docker exec ragflow-mysql mysqldump -uroot -pMICONTRASEÑA rag_flow > ragflow_dump.sql

📂 Esto generará un archivo ragflow_dump.sql en tu directorio actual (ejemplo: C:\CodeProjects\Agents\ragflow\docker\).

## 📂 8. Respaldo de PDFs y artefactos desde MinIO

RAGFlow utiliza **MinIO** como almacenamiento de objetos. Allí se guardan los archivos PDF originales y otros artefactos relacionados al procesamiento de documentos.

---

### 8.1 Acceder al contenedor MinIO

```bash
docker ps


Identifica el contenedor de MinIO, normalmente llamado:
quay.io/minio/minio ...   NAMES: ragflow-minio


8.2 Obtener las credenciales de acceso

Dentro del contenedor de MinIO se configuran las credenciales. Ejecuta:

docker exec ragflow-minio env | grep MINIO


Ejemplo de salida:

MINIO_ROOT_USER=admin
MINIO_ROOT_PASSWORD=supersecret


8.3 Acceder al panel web de MinIO

En tu navegador abre:
http://<IP_LOCAL>:9001

o desde el mismo host:

http://localhost:9001

Usa las credenciales obtenidas (MINIO_ROOT_USER / MINIO_ROOT_PASSWORD).

8.4 Descargar archivos con la CLI de MinIO

Primero instala el cliente oficial mc (MinIO Client):
👉 https://min.io/docs/minio/linux/reference/minio-mc.html

Luego configura un alias para el servidor local:

mc alias set ragflow http://localhost:9000 admin supersecret

Verifica la conexión:
mc ls ragflow


Deberías ver los buckets, por ejemplo:
[2025-09-22 14:10:35 UTC]     0B documents/
[2025-09-22 14:10:35 UTC]     0B artifacts/

8.5 Descargar todos los documentos PDF

mc cp --recursive ragflow/documents ./ragflow_documents_backup/

8.6 Descargar todos los artefactos procesados

mc cp --recursive ragflow/artifacts ./ragflow_artifacts_backup/


📦 Resultado del respaldo

Base de datos MySQL: exportada en ragflow_dump.sql (estructura + embeddings + chunks + metadatos).

Documentos PDF originales: descargados desde MinIO a ./ragflow_documents_backup/.

Artefactos de procesamiento: descargados desde MinIO a ./ragflow_artifacts_backup/.

Con estos tres elementos puedes migrar y reconstruir RAGFlow en otro entorno, o integrarlo con Supabase o cualquier otra base de datos corporativa.
